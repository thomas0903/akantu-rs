# Cohesive scalability test — strict oracle with the MUMPS static solve, x86_64, D-050 pin

Reference of the Rust driver's MUMPS static solve
(`crates/akantu-bench/tests/perf_cohesive_mumps.rs`, feature `mumps`).
One case, `coh_np1`: the upstream benchmark
(`benchmarks/cohesive-perf/inputs/material-cohesive.dat`) on the frozen
h = 0.12 cube (`../perf_cohesive/meshes/cube-h0.12.msh`), 1,500 steps,
`blocked_node = global`, `energy_precision = 17`, `output_energy = true`, one
rank, the upstream static solver `_auto` = MUMPS 5.7.3. Generated by the C++
harness (`run-one.sh`, `strict` install, JOSS-patch emulation of the
`fillNodesToElements` rebuild: bitwise-neutral, `fixtures/perf_cohesive/
determinism.json`) in `akantu-oracle:dev` `sha256:2da26d87…` with the image's
D-050 pins (`OPENBLAS_CORETYPE=Haswell`, `OPENBLAS_NUM_THREADS=1`,
`OMP_NUM_THREADS=1`, `AKA_SEED=1`, `SCOTCH_PTHREAD_NUMBER=1`) on an
x86_64 Linux virtual machine (AMD EPYC 9455), 2026-11-11; command and full
provenance in `coh_np1/provenance.json`.

**Qualification (D-035(b)):** three fixed-seed repetitions, byte-identical
`energies.csv`, `insertions.csv` and `summary_rank0.json` (digests per
repetition in `provenance.json`; `summary.json` differs only in the two
timing fields). Same counts as `../perf_cohesive_x86_64/coh_np1` (404
cohesive elements, 294 insertion steps from step 710, identical
`insertions.csv`); its energies differ (`../perf_cohesive_x86_64` was
generated before the D-050 OpenBLAS pin, image `45122c21…`): that directory
is not replaced. Use: the exact rule on x86_64 with the same pin only (the
test prints a diagnostic elsewhere).

`input.dat` is the C++ run's input verbatim (mesh path inside the oracle
container); the Rust test runs the same problem from
`../perf_cohesive/coh_np2_global/input.dat` (`blocked_node = global`,
17 digits; at one rank `export_partition` has no effect).

`partition-np4.csv`: the oracle's Scotch partition of the same problem on 4
ranks (`export_partition = true`, `AKA_SEED = 1`, `SCOTCH_PTHREAD_NUMBER = 1`,
strict install), byte-identical in the export run and in the three 4-rank
runs of campaign `item1-h012` (SHA-256 `bb833e0a…`); the Rust test replays it
at 4 ranks (the 2-rank partition is `../perf_cohesive_x86_64/coh_np2_global/
partition.csv`, equal to today's export).
