# Code of conduct

This project follows the Contributor Covenant, version 2.1:
https://www.contributor-covenant.org/version/2/1/code_of_conduct/

It applies in every space of the project: the issue tracker, pull requests,
discussions and any other channel the project uses.

## Reporting

Report unacceptable behaviour privately to the maintainer through the
repository's private reporting form: on GitHub, the "Security" tab, then
"Report a vulnerability", with "Code of conduct" at the start of the title.
Only the maintainer can read the report. The maintainer reviews every report,
keeps the reporter's identity confidential and applies the enforcement
guidelines of the Contributor Covenant.
