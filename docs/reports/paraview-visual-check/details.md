## 3. The differing files read directly (`vtu_diff.py`)

`scripts/paraview/vtu_diff.py` reads both files of every differing pair
directly (XML and base64, no ParaView) and classifies every array:
`same` (decoded values identical: only the encoding differs), `ud110-layout`
(upstream writes each `c`-component tuple as a zero-filled `c × c` square
whose top-left block equals the port's tuple bitwise), `ud110-layout+ud111`
and `ud111` (the same, apart from the never-written out-of-plane shear
entries of a padded 2-D stress), `ud114` (upstream's base64 stream of an
empty array is invalid, the port's is valid), `short` / `long` (upstream's
array holds fewer / more values than its piece needs), `values` (same
layout, different numbers), `one-side`. The base64 length header of every
upstream array counts its own 4 bytes (UD-114, reproduced by the port).
